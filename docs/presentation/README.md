This folder holds `symcc-overview.html`, a one-file slide deck with pictures of symcc's features, plus a few ideas about autonomous agent organizations.
`symcc-workspace-vision.html` is a second deck: how symcc would look as one board over a whole workspace (several repos, plain folders and outside work), marked by what exists today, what is designed and what is only an idea.
To open either one, double-click the file or open it in a browser, then use the arrow keys or the Prev and Next buttons.
