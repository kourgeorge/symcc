# symcc explainer video: narration script

Length: about 2 minutes. Read by a text-to-speech voice (Kokoro), so the spoken text has no symbols, file paths or code. Each part has a scene name, the narration, and what the picture shows. The story: three problems with Claude Code today, and how symcc solves each one. The narration is about 276 words (1 minute 50 seconds when read).

## Scene 1: Three problems (about 25 seconds)

**Narration:**
Claude Code is great, but today it has three problems. One. It does one task at a time, and you wait. Two. You cannot see what each helper agent does, or how the work was split between them. Three. It stops when you stop. Nothing moves your project forward while you are away.

**On screen:** Three red cards appear one by one. One: a single long task with ideas waiting beside it. Two: an agent with three helpers marked with question marks. Three: a sleeping screen, "the project stands still".

## Scene 2: symcc in one breath (about 15 seconds)

**Narration:**
symcc solves all three. It is a plugin for Claude Code. You talk to one lead, in your normal chat. The lead keeps a shared task board, and workers take the tasks from it.

**On screen:** The logo and "a plugin for Claude Code", then you, the lead, the board and the workers around it.

## Scene 3: Problem one solved (about 20 seconds)

**Narration:**
First, no more waiting. Workers run tasks side by side, each in its own copy of your code, so they never get in each other's way. Your tests must pass before anything is merged. And when one task needs another, the lead puts them in the right order.

**On screen:** Three worker folders, each with its own branch. A green "tests pass, then merge" mark. A task card that waits for another one.

## Scene 4: Problem two solved (about 30 seconds)

**Narration:**
Second, you can see everything. Every task on the board shows what it is, why it exists, which files it may change, and where it came from. You also see its tries, the worker's report, and the time and tokens it cost. Review each change and approve it yourself, or choose auto mode, and passing work is merged right away. If a worker has a question, it waits for you.

**On screen:** One task page filling in line by line: what, why, files, where it came from, tries, report, time and tokens. Then the review mode and auto mode boxes, and a task waiting under "needs you".

## Scene 5: Problem three solved (about 20 seconds)

**Narration:**
Third, it keeps going while you are away. Scouts wake up on timers and look for bugs, missing tests, and gaps. The lead turns what they find into tasks, and workers do them. You come back to finished, tested work.

**On screen:** The Scouts tab: a scout goes from due now to running to done. A new task appears on the board and a worker starts it.

## Scene 6: Get it (about 15 seconds)

**Narration:**
symcc is free and open source, under the MIT license. Install it as a plugin for Claude Code, with one command. symcc. Many agents, one board, working while you are away.

**On screen:** Free, open source, MIT. The install command in a terminal, then the logo with the repository link and the line about autonomous coding.
