A team lead for your coding agents

symcc is an agent organization that runs inside your coding agent. You talk to a lead; the lead puts the work on a board, workers build it in parallel, and nothing merges until your tests pass.

Install Read the guide

What it is

  • The lead is your normal chat. It takes your ideas at any time, turns them into tasks, decides their order and asks you only for real decisions.
  • Workers build tasks in parallel, each in its own git worktree and branch, so your branch is untouched until merge.
  • Scouts run on a timer and only look: they find bugs, missing tests and outdated parts, and the lead turns what they find into tasks.
  • The merge line checks each change stays inside its files, runs your tests, lets you review the diff, and merges one change at a time.

The board

One list for work you asked for and work scouts found: todo, doing, review, done.

Install

Claude Code

You need Claude Code and git. There is no build step.

claude plugin install symcc --marketplace kourgeorge/symcc

Then start Claude Code in your project. The board opens by itself; if not, run /symcc.

OpenCode

symcc also runs in OpenCode 2.3 or newer (a first version). From a clone of symcc:

git clone https://github.com/kourgeorge/symcc && sh symcc/scripts/install-opencode.sh

Or, with no clone:

opencode plugin add github:kourgeorge/symcc

Pick one of the two ways. The details are in the guide.
