A team lead for your coding agents

symcc is an agent organization that runs inside your coding agent. You talk to a lead; the lead puts the work on a board, workers build it in parallel, and nothing merges until your tests pass.

Install Read the guide

What it is

Coding agents are fast. The hard part is keeping track of the work: new ideas come up while an agent is busy, and small items quietly drop out. symcc keeps that list for you and has a team work through it.

  • The lead is your normal chat. You talk to one place, at any time. It turns your ideas into tasks, decides their order and asks you only for real decisions.
  • Workers build tasks in parallel. Each has its own folder and branch, so they cannot overwrite each other and your branch is untouched until merge. Each task lists the files it may change, so a stray edit is refused instead of showing up in the diff.
  • Scouts run on a timer and only look. They find bugs, missing tests and outdated parts while you are away. The lead turns what they find into tasks, so a scout never changes your project by itself.
  • The merge queue lets finished changes take turns: it runs your tests, lets you review the diff, and merges one change at a time. This way the code that was tested is exactly the code that merges.

symcc also has an optional checker, an agent that tries to break each change before the tests run. The file checks catch honest mistakes; they are not a security boundary. The guide explains why each part is there.

The board

One list for work you asked for and work scouts found: todo, doing, review, done. It is a plain file, so the work is still there after the chat ends.

Install

Claude Code

You need Claude Code and git. There is no build step.

claude plugin install symcc --marketplace kourgeorge/symcc

Then start Claude Code in your project. The board opens by itself; if not, run /symcc.

OpenCode

symcc also runs in OpenCode 2.3 or newer (a first version). From a clone of symcc:

git clone https://github.com/kourgeorge/symcc && sh symcc/scripts/install-opencode.sh

Or, with no clone:

opencode plugin add github:kourgeorge/symcc

Pick one of the two ways. The details are in the guide.
