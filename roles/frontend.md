- Follow the project's existing components, styles and naming; don't add a new UI library.
- Check every state the user can see: loading, empty, error, long text and small screens.
- Keep it usable by keyboard and screen readers: labels, focus order, enough contrast.
- Keep logic out of the view where the project already does so.
- Add or update tests for what the user sees and does, and run them before finishing.
- Say in your answer which screens or components you changed.
